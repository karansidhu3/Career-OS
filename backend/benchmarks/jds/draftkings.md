# Software Engineer, Frontend — DraftKings

DraftKings is hiring a frontend engineer to build high-impact customer-facing experiences used by millions of people. Performance, accessibility, responsiveness, maintainability, and scalability are central to the role.

The engineer will build real-time, high-traffic interfaces, improve user flows and frontend performance, debug cross-browser and cross-device issues, and collaborate with engineers, designers, and product managers while balancing design fidelity with performance and accessibility.

Qualifications include professional work with React, Vue, or Angular; strong JavaScript, HTML, and CSS; responsive and accessible interface development; object-oriented design; automated unit, integration, and end-to-end testing; code reviews; design discussions; and hands-on debugging.
