# Quantitative Developer — RBC

RBC's Quantitative Investment Strategies development team builds calculation infrastructure for structuring, trading, and risk management. The role designs scalable compute solutions while preserving flexibility for testing new quantitative strategies.

Responsibilities include analyzing computational patterns, designing calculation frameworks and scalable computation infrastructure, migrating user code, maximizing compute performance, improving system stability, reducing duplicated work, and collaborating with quants, traders, and global technology teams.

Strong Python and software engineering fundamentals are required. Distributed computation, large-scale systems, distributed caches, performance optimization, capital markets, financial calculations, quantitative strategies, and enterprise architecture are preferred.
