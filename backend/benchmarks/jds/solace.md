# Full-Stack Software Developer — Solace

Solace's Launchpad team builds the tools and automation for deploying and upgrading Solace brokers across public clouds and self-managed environments. The role contributes to upgrade automation, cloud broker deployments, internal operational tools, and full-stack product features.

The stack is Java and Spring Boot on the backend and React on the frontend. The engineer will write automated tests, contribute to CI/CD, document and demo work, and gain exposure to Kubernetes and cloud-native infrastructure.

Core qualifications include Java, Spring Boot, React or another modern JavaScript framework, Kubernetes fundamentals, one major cloud provider, REST APIs, databases, automated tests, and AI-assisted development. Event-driven architecture, event brokers, containers, microservices, GitHub Actions, and deeper Kubernetes experience are preferred.
