# Software Engineer, Landscape — Canonical

Canonical is hiring a software engineer passionate about open source software, Linux, Python, and web services at scale. Landscape deploys, monitors, and manages fleets of Ubuntu systems, including package management, observability, security, compliance, hardware inventory, and automation.

The engineer will collaborate on a distributed team, write high-quality features and bug fixes, modernize the Landscape codebase, maintain strong automated testing, participate in code and architecture reviews, own problems through delivery, assist with release management, and collaborate with DevOps for Landscape SaaS.

The role requires public-facing APIs and web applications, preferably using Python; Python frameworks such as Flask or Django; databases and ORMs, with PostgreSQL preferred; and comfort using Ubuntu as both a development and deployment platform.
