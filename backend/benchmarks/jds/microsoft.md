# Software Engineer — Microsoft

Microsoft's Azure Data organization builds the platform foundations behind Fabric, Azure SQL Database, Cosmos DB, PostgreSQL, Azure Data Factory, Synapse, Service Bus, Event Grid, and Power BI. The role integrates Azure technologies to deliver reliable systems at scale.

Responsibilities include production and deployment automation, testing in simulated environments, product and test code review, diagnosability, reliability, testability, maintainability, secure design, scaling, performance, feature experimentation, telemetry, monitoring, and collaboration with data scientists and product managers.

The role requires a computer science degree or equivalent experience and software engineering experience in languages including C, C++, C#, Java, JavaScript, or Python.
